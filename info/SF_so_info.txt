## What `libsf_r31.so` actually is

This is a **native Android SurfaceFlinger screen-capture helper library**.

The strongest evidence is that it directly imports Android's:

```text
android::ScreenshotClient
android::SurfaceComposerClient
android::GraphicBuffer
android::gui::IScreenCaptureListener
android::Fence
```

and exports functions named:

```text
surf_info
surf_info2
surf_screenshot_rect2
surf_screenshot_rect_fix
surf_update2_a28
surf_update_rect2_a28
surf_update_req2_a28
dpy_info
rotate
adjust_orientation
partial_copy
```

So this is **not an encoder**. Its primary job is interacting with Android's display/surface system and obtaining screen pixels.

We shouldn't conclude yet that it does dirty-region detection — but it's definitely something we should investigate.
